# Interaction
## Make decision
when you have to make a choice, ask user, and
**do never make a decision on your own**.

## Version Controls matter
**make sure** you can back to previous version, 
remember, `.git`'s size matters nothing.

## Make notes
save all the useful infomation in [memory pool](./memory.md).

## Encapsulate utils
if you think that a Script will be used again, save it in [debug/](../../debug/),
but you must ask user beforehand.
